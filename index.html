What is C++?

C++ is a small, carefully extended dialect of C that keeps C compatibility while adding ergonomics, stronger typing in key places, and safe language features meant for modern systems programming. It compiles with the gpcc compiler which focuses on fast builds, small runtime, and predictable code generation.

Quickstart

Create hello.cp (C++ source):

// hello.cp
#include <stdio.h>

func main() : int {
  println("Hello, C^++!");
  return 0;
}

Build with gpcc:

git clone https://github.com/c-to-the-power-of-plus-plus/source.git
cd source
make
./gpcc -o hello hello.cp
./hello
