C++ — Language Spec (summary)

Design goals

  • Preserve compatibility with existing C where practical.
  • Add safer default constructs (optional ownership/borrow semantics).
  • Small runtime and clear ABI for systems programming.

Core syntax

C++ uses familiar C-like syntax with a couple of high-level extensions.

Function

func add(a: int, b: int) : int {
  return a + b;
}

Printing and std helpers

println("value:", 42)

Pattern matching

match (x) {
  case 0: println("zero")
  case 1: println("one")
  case _: println("other")
}

Types

TypeDescription
intSigned integer (target-dependent width, defaults to 64-bit on 64-bit targets)
u32, u64Explicit unsigned widths
float, doubleFloating point types
ptr TRaw pointer to T compatible with C pointers

Interoperability with C

C++ aims for easy interop with existing C code. Use the extern keyword for linking C functions and headers. The ABI follows standard C ABI for primitive types and pointers.

Examples

// factorial.cp
func fact(n: int) : int {
  if (n <= 1) {
    return 1;
  }
  return n * fact(n - 1);
}

func main() : int {
  println("6! =", fact(6));
  return 0;
}

See gpcc compiler guide for build and linking examples.
