gpcc — Compiler Guide

Basic usage

# Compile single file to executable
gpcc -o prog prog.cp

# Compile to object file
gpcc -c prog.cp -o prog.o

# Link object files
gpcc prog.o other.o -o final

gpcc accepts C-like flags and some additional high-level flags described below.

Important flags

FlagMeaning
-o <file>Output file
-cCompile only (no link)
-O0 / -O1 / -O2 / -O3Optimization level
-gInclude debug info
-I <dir>Add include path
-L <dir> -l<lib>Linker path / library
--emit=asm|llvm|objEmit specific intermediate

Building the compiler (from repo)

git clone https://github.com/c-to-the-power-of-plus-plus/source.git
cd source
# run the provided Makefile
make
# run tests
make test

Use environment variables like CC and AR to customize the toolchain used to bootstrap gpcc where supported by the Makefile.

Cross-compilation and linking

gpcc delegates most linking to the platform linker (ld or gold). For cross-compilation:

# Example: targetting arm-linux
export CC=arm-linux-gnueabihf-gcc
make

Troubleshooting

  • Undefined reference at link time — ensure you passed libraries with -l and search paths with -L.
  • Build fails on missing header — install development headers or add include path with -I.
  • Segfault in generated binary — re-run with -g and inspect with gdb; ensure pointer/FFI boundaries are correct when mixing with C.

Examples

// build and run
gpcc -O2 -o hello hello.cp
./hello

// build library
gpcc -c lib.c -o lib.o
ar rcs libmylib.a lib.o
gpcc main.cp -L. -lmylib -o app
