Verify downloads

  1. Download the asset and the corresponding .sha256 file from the same release.
  2. Run: 
    sha256sum gpcc-0.3.0-linux-x86_64.tar.gz
# or on macOS
shasum -a 256 gpcc-0.3.0-macos.tar.gz
  3. Optionally verify a detached GPG signature (if provided): 
    gpg --keyserver hkps://keys.openpgp.org --recv-keys YOUR_PGP_KEY_ID
gpg --verify gpcc-0.3.0-linux-x86_64.tar.gz.asc gpcc-0.3.0-linux-x86_64.tar.gz

We recommend verifying checksums and signatures for production use.

Install from source

To build gpcc from source on Unix-like systems:

git clone https://github.com/c-to-the-power-of-plus-plus/source.git
cd source
make
# Optionally install to /usr/local
sudo make install

The project uses a simple Makefile. On Windows you can use MSYS2 or WSL to build, or download the prebuilt zip.

Notes for package maintainers

  • Provide deterministic builds where possible.
  • Add gpcc to Homebrew (macOS) and community package repos for Linux distributions.
  • Sign releases with a PGP key and publish fingerprint on the website.
Need CI artifacts or nightly builds? See the project's GitHub Actions or open an issue requesting additional targets.
